# EventSL - LONESTAR 度假SL与回退模组

适用于游戏《孤星猎人》（LONESTAR）的度假与事件 S/L（保存与载入）模组。

---

## 🌟 核心功能

1. **【头像下方专属 SL 按钮】**
   - 在度假界面和事件界面中，飞行员头像正下方显示贴合原版科幻橙风的 `【整体 SL】` 按钮。
   - 宽度自适应对齐头像，点击无多余二次确认弹窗，一键直接生效。
2. **【整轮度假一键重置】**
   - 每次刚进入度假界面时自动创建起点备份。
   - 随时点击 `【整体 SL】` 可直接回退到刚进入该轮度假时的起点，重置所有已进行事件与天数。
3. **【跨帧延迟备份保护（v1.4.1）】**
   - 针对战斗结算最后一项选择类奖励（装备、宝物、天赋）底层回调顺序倒置的特有问题，采用跨帧延迟备份与强制主动保存机制，确保任何战斗奖励在 SL 后绝不丢失。
4. **【退出即重置（可选设置）】**
   - 可在游戏内 Mod 设置面板中开启“返回主菜单自动重置度假”。

---

## 📦 安装方法

### 方式一：直接安装
将 `dist/EventSL/` 文件夹复制到游戏的开发模组目录：
```text
%USERPROFILE%\AppData\LocalLow\Shuxi\LONESTAR\Mods\Dev\EventSL\
```

### 方式二：一键脚本
双击运行项目根目录下的 `install.bat`，脚本将自动编译并安装到游戏目录。

---

## 🛠️ 源码构建

- **开发框架**：.NET Standard 2.1 / C# 9.0
- **构建依赖**：LONESTAR 游戏根目录组件（Harmony、Assembly-CSharp、UnityEngine 等）
- **编译命令**：
```bash
dotnet build EventSL.csproj -c Release
```
